Design of a suspension system

Context

CAD project involving the parametric design of a complete suspension system on NX, allowing key parameters (dimensions, number of holes, shape, etc.) to be adjusted for each component.

Skills Acquired

· Parametric and configurable 3D modeling
· Mechanical component design (suspension arms, bearings, hub, rim, brake disc, spring)
· Kinematic constraint management (camber angle adjustment per specification)
· Autonomous project management from specification to final assembly

Software Used

· Siemens NX
